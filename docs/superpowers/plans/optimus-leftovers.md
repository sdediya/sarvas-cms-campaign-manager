  name.
- The already pinned local v1.0.2 collection was then run as
  `npx ng generate @openng/optimus-ui:migrate-from-primeng --force`.

  reported the expected Angular 22 versus Angular 21 peer conflict. Dependencies
  were installed separately with npm's force option.
